# दर्द-ए-दिल (Hindi Sad Songs Radio)

Non-stop 24/7 all-time-hit and trending Hindi Sad Songs & Heartbreak Classics radio featuring Arijit Singh, KK, Kumar Sanu, Sonu Nigam, B Praak, Atif Aslam, and more.

## Development & Local Access

To run the application locally:

```sh
npm install
npm run dev
```

The application will be accessible on your local network at `http://localhost:8080/`.
